# Homework 5 (Sed Text Cleaning Pipeline)
In this assignment I created a text processing pipeline with SED to clean amazon review text and statistics.

1) Selected a product with many reviews column from dataset.
2) I cleaned the review using sed by removing tags and common stopwords, and normalized whitespace so it becomes consistent and efficient to analyze.
3) I tokenized the review tokens by splitting non alphanumeric characters and converting them to lowercase.
4) Counted token frequencies using sort and uniq
5) From the token counts we can see that words such as game, fun adn love appear frequently
